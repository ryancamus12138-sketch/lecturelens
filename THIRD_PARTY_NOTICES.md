# Third-party software

LectureLens bundles the following libraries unmodified in `lib/`. Their full licence texts are in `lib/licenses/`.

| Library | Version | Licence | Used for |
|---|---|---|---|
| [PDF.js](https://github.com/mozilla/pdf.js) (`pdfjs-dist`) | 4.10.38 | Apache-2.0 | Reading text from uploaded PDF slides |
| [JSZip](https://github.com/Stuk/jszip) | 3.10.1 | MIT (dual-licensed MIT / GPL-3.0-or-later; used under MIT) | Reading text from uploaded .pptx slides |
| [marked](https://github.com/markedjs/marked) | 12.0.2 | MIT | Rendering Markdown notes |
| [DOMPurify](https://github.com/cure53/DOMPurify) | 3.4.18 | Apache-2.0 (dual-licensed MPL-2.0 / Apache-2.0; used under Apache-2.0) | Sanitising rendered notes |
| [KaTeX](https://github.com/KaTeX/KaTeX) | 0.16.47 | MIT | Rendering formulas (includes KaTeX fonts) |
