# LectureLens 课堂助手

[English](README.md) | 简体中文

看课程录播用的 Chrome 侧边栏：开倍速也跟得上的双语字幕、分段笔记、读取画面里的 PPT 和手写、提问、整门课搜索。为 Echo360 做了专门适配，其他带字幕的视频网站也能用。

> 非官方工具，与任何大学、Echo360、OpenAI、DeepSeek、Anthropic 均无关联。

## 安装

1. 下载本仓库（**Code → Download ZIP**），解压到一个固定位置。
2. 打开 `chrome://extensions`，开启右上角的**开发者模式**。
3. 点**加载已解压的扩展程序**，选择解压出来的文件夹。
4. 点工具栏的 LectureLens 图标打开侧边栏。

更新时覆盖同一个文件夹，再点扩展卡片上的刷新按钮。换文件夹位置会丢失设置和笔记。

## 配置

LectureLens 不自带模型。打开**设置**页填写你自己的接口：

| 接口类型 | 填写 |
|---|---|
| OpenAI 兼容（DeepSeek、OpenAI、Gemini、通义等） | Base URL、API key、模型名 |
| Anthropic (Claude) | API key、模型名 |
| 本机 Codex（实验性） | 见[下文](#用-codex-cli-做总结实验性) |

填完点**测试连接**。总结和提问需要支持图片的模型，翻译不需要。可以翻译用便宜的模型，总结换另一家接口。

界面默认是英文，点侧边栏顶部的按钮切换中文。

## 使用

| 标签页 | 作用 |
|---|---|
| **字幕** | 打开录播并播放，整节课会提前翻译好。点任意一句跳转。 |
| **总结** | 播放到每段末尾自动出要点。**扫描整节课**可以不看视频，自动截取课件画面并总结全部。可导出 PDF、Markdown、HTML，时间戳可点击。 |
| **提问** | 针对这节课提问，回答会结合字幕、课件、笔记和当前画面。 |
| **全课** | 打开过的每节课自动收录，可跨课次搜索或向整门课提问。 |
| **设置** | 模型、上传课件（.pptx / .pdf）、导入字幕（.vtt / .srt）、目标语言、分段长度。 |

- **Echo360**：自动读取完整转录。
- **其他网站**：打开播放器的 CC 字幕，或导入字幕文件。
- **完全没有字幕**：几秒后“总结”页改为只根据截图生成笔记。没有语音识别，老师只在口头讲的内容不会被记录。

## 用 Codex CLI 做总结（实验性）

如果你有 ChatGPT 订阅并装了 [Codex CLI](https://github.com/openai/codex)，总结和提问可以走本机的 Codex，不用按量付费的 API。

1. `codex login`，用 ChatGPT 账号登录。
2. 在本文件夹运行 `python3 codex-bridge/bridge.py`，保持窗口开着，复制显示的口令。
3. 设置页勾选**总结 / 答疑改用另一家接口**，类型选**本机 Codex**，粘贴口令，再选模型和推理强度。

桥接程序只监听 `127.0.0.1`，需要口令，每次请求在一个空的只读目录里运行一次 `codex exec`。它比 API 慢，并消耗你的 Codex 额度。是否符合你的订阅条款请自行确认。

## 已知限制

- Echo360 的转录通过未公开的接口读取，可能失效。
- 扩展对所有网站生效（为了在任意视频页找到字幕），不用时可以关掉。
- 提示词是中文写的，针对“英文授课、中文笔记”；其他语言组合未测试。
- 全课搜索是关键词匹配，不是语义检索。
- 时间戳链接只在装了 LectureLens 的 Chrome 里能跳转。
